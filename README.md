# Hi, I'm Eslam Fayek 👋

Full-stack developer based in Cairo. I build WhatsApp API products, AI agents, automations and the servers they run on.

I founded and built **[WhatsArab](https://whatsarab.com)**, a live SaaS on the official WhatsApp Cloud API: a shared team inbox, broadcasts and message templates, a visual flow builder, AI agents that answer from a business's own knowledge base, webhooks and a public REST API. I also designed and run its production setup on AWS.

### Open source

- **[whatsarab-sdk](https://github.com/WhatsArabHQ/whatsarab-sdk)**: official SDKs for Node.js/TypeScript (`@whatsarab/sdk` on npm) and Python (`whatsarab` on PyPI)
- **[n8n-nodes-whatsarab](https://github.com/WhatsArabHQ/n8n-nodes-whatsarab)**: n8n community node to send WhatsApp messages and templates and trigger workflows from WhatsArab webhooks
